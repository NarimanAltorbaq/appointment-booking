# Appointment Booking System

نظام حجز مواعيد لعيادة/صالون مبني بـ ASP.NET Core Razor Pages.

## المميزات
- صفحة حجز للزبائن
- لوحة إدارة لتأكيد الحجوزات أو إلغائها
- قاعدة بيانات SQLite عبر Entity Framework Core

## التقنيات
C#, ASP.NET Core, Entity Framework Core, SQLite, Bootstrap

## التشغيل
    cd BookingApp
    dotnet run
